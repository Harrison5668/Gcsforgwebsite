# CSW70 Global Women Leadership Summit Website

This is the official website for the Global Women Leadership Summit & Impact Award Ceremony, a parallel event of the 70th Session of the Commission on the Status of Women (CSW70) at the United Nations.

## Features

- **Bilingual Support**: Full Chinese/English language toggle
- **Responsive Design**: Mobile-first design that works on all devices
- **Modern UI**: Clean, professional interface with smooth animations
- **Video Integration**: Embedded venue tour video
- **Accessibility**: Semantic HTML and ARIA-friendly structure

## Structure

- `index.html` - Main HTML structure
- `styles.css` - CSS styling with responsive design
- `script.js` - JavaScript for language toggle and interactions

## Sections

1. **Hero Section** - Main title and call-to-action
2. **About Section** - Event details, objectives, vision & mission
3. **Agenda Section** - Event schedule information
4. **Speakers Section** - Featured speakers (placeholder)
5. **Venue Section** - Venue details with video tour
6. **Register Section** - Registration information

## Usage

Simply open `index.html` in a web browser to view the website. No build process or server required.

## Language Toggle

Click the language button in the navigation bar to switch between English and Chinese. The preference is saved in browser localStorage.

## Customization

- Update content in `index.html`
- Modify colors and styles in `styles.css` (see CSS variables at the top)
- Adjust behavior in `script.js`
